JANANI S — PORTFOLIO WEBSITE

Files:
- index.html: website content
- style.css: design and responsive layout
- assets/janani-photo.jpeg: your profile photo
- certificates/: add your certificate PDFs or images here

TO PUBLISH WITH GITHUB PAGES:
1. Sign in to GitHub and create a new public repository named: portfolio
2. Open the repository, choose Add file > Upload files.
3. Upload index.html, style.css, and the assets and certificates folders (upload the files inside them).
4. Commit the upload to the main branch.
5. Open Settings > Pages.
6. Under Build and deployment, choose Deploy from a branch.
7. Select Branch: main and Folder: / (root), then click Save.
8. Wait a minute or two. Your site should appear at:
   https://janani-s-1807.github.io/portfolio/

If you already have a repository named portfolio, upload/replace these files there instead of creating another one.
